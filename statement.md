# Project Statement

## Project Title
Bus / Transport Booking System

## Problem Statement
Manual bus booking can become confusing when seat availability, passenger details, fare calculation, and cancellations are handled separately. This project provides a small command-line system that combines these common booking operations into one menu-driven application.

## Scope
The project focuses on basic bus booking operations for predefined routes. It supports route display, seat booking, booking cancellation, passenger search, and fare calculation.

The project does not currently include online payment, user accounts, live bus tracking, or permanent database storage.

## Target Users
- Small transport operators for a basic local booking workflow
- Students learning Python programming
- Users who need a simple terminal-based booking simulation

## High-Level Features
- Route and seat availability display
- Passenger seat booking
- Ticket ID generation
- Booking cancellation with refund calculation
- Passenger search
- Fare calculation
- Input validation
- Unit testing

## Expected Outcome
The project demonstrates how Python data structures and modular programming can be used to model a simple real-world transport booking workflow.
